# Ultron Dokümantasyonu (`docs`)

- Doküman düzeni: `docs/superpowers/specs` (tasarım), `docs/superpowers/plans` (uygulama planları) ve `docs/reports` (ölçüm/kabul raporları).
- Tüm dokümantasyon dili Türkçe olmalıdır.
- Onaylanmış bir tasarım özelliğini (spec) asla sessizce değiştirmeyin; değişiklikleri tarihli notlar (dated notes) ekleyerek yapın.
